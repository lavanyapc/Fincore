# FinCore

A digital banking system built with Spring Boot, focused on implementing secure banking services and core financial operations.

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- JWT Authentication
- Spring Data JPA
- PostgreSQL
- Maven
- Docker (PostgreSQL)

## Features Implemented

- User registration and login
- JWT-based authentication
- Account creation
- Role-based security
- Banking entities and database design
- JPA repositories
- DTO-based API requests and responses
- Account number generation

## Project Structure

```
src/
 ├── controller/
 ├── service/
 ├── repository/
 ├── entity/
 ├── dto/
 ├── security/
 └── config/
```
